# Занятие «Прогнозирование и моделирование» — комплект материалов

Информатика, 10 класс (экономический профиль), 90 минут. Темы: регрессионный анализ (`ЛИНЕЙН`/LINEST), прогнозирование временных рядов (`ПРЕДСКАЗ.ЛИНЕЙН`/FORECAST, `ТЕНДЕНЦИЯ`/TREND), what-if анализ (Подбор параметра, Таблица данных, Диспетчер сценариев).

## Порядок подготовки

1. Открыть `Практикум_решение.xlsx` в Excel и пройти все три листа (5 минут) — числа должны совпадать с разделами «Ответы» в конспекте.
2. Раздать ученикам `Практикум_данные.xlsx` (по сети / флешка / ЭЖ) и распечатать `03_Раздатка_ученика.docx`, `04_Проверочный_тест_ученик.docx`, `05_Домашнее_задание_ученик.docx`.
3. Проверить версию Excel в классе: `ПРЕДСКАЗ.ЛИНЕЙН` и `ПРЕДСКАЗ.ETS` требуют Excel 2016+. Для LibreOffice / Google Sheets см. раздел «Совместимость» в конспекте.

## Ключевые числа (для быстрой сверки)

- 1А: `y = 139,1 + 3,68·x`, R² = 0,98; прогноз при 150 → ≈ 691.
- 1Б: при цене −4,84, при рекламе +29,7, a = 883,4, R² = 0,993; прогноз (100; 5) → ≈ 548.
- 2А: `y = 294,5 + 7,09·t`; I кв. 2026 → 471,6 / 478,7 / 485,8, итого ≈ 1436.
- 3: базовая прибыль 32 000; цена для 30 000 → 138,4 (или 171,6); макс. FC → 72 000; безубыточность 91,6 и 218,4; оптимум P\* = 155 (32 200); сценарии 3 000 / 32 000 / 55 000.
