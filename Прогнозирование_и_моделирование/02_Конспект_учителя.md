## 0. Мотивация (3–10 мин)

Кейс: в школе открывается кафе-точка с кофе. Управляющему нужно ответить на три вопроса:

1. *Сколько напитков продадим в неделю, если поставим цену 100 руб. и потратим 5 тыс. на рекламу?* → нужна **зависимость** (регрессия).
2. *Какая будет выручка в январе–марте следующего года?* → нужен **прогноз по времени** (временной ряд).
3. *Какую цену назначить, чтобы заработать 30 тысяч? Что будет, если аренда подорожает?* → нужен **анализ решений** (what-if).

Ключевые понятия для доски:

- **Модель** — упрощённое описание объекта формулами. Есть *входы* (параметры), *выходы* (результаты) и *связи* (формулы). В Excel модель — это лист с ячейками-входами и ячейками-формулами.
- **Прямая задача:** заданы входы → считаем выход. **Обратная задача:** задан желаемый выход → ищем вход (Подбор параметра).
- **Прогноз** — вывод модели о будущем или о не наблюдавшихся значениях. Всегда с погрешностью.

## 1. Регрессионный анализ (10–20 мин)

### Что рассказать

- Диаграмма рассеяния: по оси X — реклама, по Y — выручка. Точки «тянутся» вдоль прямой.
- Линейная модель `y = a + b·x`. `b` — **наклон**: на сколько меняется `y` при росте `x` на 1. `a` — **свободный член**: значение `y` при `x = 0` (часто без экономического смысла — обсудить).
- **Метод наименьших квадратов** (МНК): проводим прямую так, чтобы сумма квадратов вертикальных отклонений точек от прямой была минимальной. Формулы в 10 классе не выводим, Excel считает сам. Для интересующихся:
  `b = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²`, `a = ȳ − b·x̄`.
- **R²** (коэффициент детерминации) — доля разброса `y`, объяснённая моделью, от 0 до 1. R² = 0,98 → 98 % изменений выручки объясняются рекламой (в рамках этих данных). R² = 0,1 → модель почти бесполезна.
- **Корреляция ≠ причинность.** Пример: продажи мороженого и число утонувших (общая причина — жара).

### Функции Excel (русские → английские имена)

| Задача | Русский Excel | Английский Excel |
|---|---|---|
| Наклон | `=НАКЛОН(y; x)` | `=SLOPE(y, x)` |
| Свободный член | `=ОТРЕЗОК(y; x)` | `=INTERCEPT(y, x)` |
| R² | `=КВПИРСОН(y; x)` | `=RSQ(y, x)` |
| Корреляция r | `=КОРРЕЛ(y; x)` | `=CORREL(y, x)` |
| Все коэффициенты сразу | `=ЛИНЕЙН(y; x; ИСТИНА; ИСТИНА)` | `=LINEST(y, x, TRUE, TRUE)` |

`ЛИНЕЙН` возвращает **массив**: первая строка `{b; a}` (сначала наклон, потом свободный член — порядок обратный привычному!). С параметром «статистика = ИСТИНА» — таблица 5 × 2:

| строка | столбец 1 | столбец 2 |
|---|---|---|
| 1 | b | a |
| 2 | ст. ошибка b | ст. ошибка a |
| 3 | **R²** | ст. ошибка y |
| 4 | F-статистика | степени свободы |
| 5 | SS регрессии | SS остатков |

- В **Excel 365/2021** результат «разливается» сам. В **Excel 2016/2019** нужно выделить диапазон (1 × 2 или 5 × 2), ввести формулу и нажать **Ctrl + Shift + Enter**.
- Чтобы взять одно число из массива в любой версии: `=ИНДЕКС(ЛИНЕЙН(y; x); 1; 1)` — наклон, `=ИНДЕКС(ЛИНЕЙН(y; x); 1; 2)` — свободный член.
- **Множественная регрессия** (`x` — несколько соседних столбцов): `=ЛИНЕЙН(y; B2:C16)`. Коэффициенты выдаются в **обратном порядке**: сначала при последнем `x`, потом при первом, в конце `a`.

### Сценарий демонстрации (3 мин)

1. Открыть `Практикум_решение.xlsx`, лист `1_Регрессия`. Показать данные 1А и диаграмму с линией тренда: на диаграмме уравнение `y = 3,68x + 139,11`, R² = 0,98.
2. Показать, что `ЛИНЕЙН` даёт те же числа (F3:F4), а `НАКЛОН`/`ОТРЕЗОК` — тоже (F8:F9). Три способа — один результат.
3. Прочитать вслух: «каждая тысяча рублей рекламы приносит в среднем 3,68 тыс. руб. выручки». Спросить: значит ли это, что 1 млн на рекламу даст 3,8 млн выручки? (Нет: экстраполяция далеко за пределы данных 20–110 тыс.)

### Ответы к практике 1

**1А** (реклама → выручка):

| Величина | Значение |
|---|---|
| Наклон b | **3,68** тыс. руб. выручки на 1 тыс. руб. рекламы |
| Свободный член a | **139,11** тыс. руб. (выручка «без рекламы») |
| R² | **0,980** |
| r | 0,990 |
| Прогноз при рекламе 150 | `139,11 + 3,68·150 ≈ 691` тыс. руб. — с оговоркой: 150 вне диапазона данных (20–110) |

**1Б** (спрос от цены и рекламы), `ЛИНЕЙН(D21:D35; B21:C35)`:

| Величина | Значение |
|---|---|
| Коэффициент при рекламе b₂ (1-й в выводе) | **+29,7** шт. на 1 тыс. руб. рекламы |
| Коэффициент при цене b₁ (2-й в выводе) | **−4,84** шт. на 1 руб. цены |
| Свободный член a | 883,4 |
| R² | 0,993 |
| Прогноз (цена 100, реклама 5) | `883,4 − 4,84·100 + 29,7·5 ≈ 548` шт. |

Вопросы для обсуждения:
- Рост цены на 10 руб. → спрос падает на ≈ 48 шт.
- Снизить цену на 10 руб. (+48 шт.) или добавить 1 тыс. руб. рекламы (+30 шт.)? По штукам выгоднее скидка, но она снижает выручку с *каждой* проданной единицы, а реклама стоит 1000 руб. При цене 100, рекламе 5 и продажах ≈ 548 шт. (выручка `100·548 = 54 800`): скидка → `90·596 ≈ 53 600` (хуже); +1 тыс. рекламы → `100·578 − 1000 ≈ 56 800` (лучше). Вывод: считать надо в рублях, а не в штуках.
- Эластичность спроса по цене в точке (P = 100, Q ≈ 548): `E = b₁·P/Q = −4,84·100/548 ≈ −0,88` — спрос неэластичный, повышение цены увеличит выручку (для продвинутых).

## 2. Прогнозирование временных рядов (35–42 мин)

### Что рассказать

- **Временной ряд** — значения одной величины через равные промежутки времени. Вместо дат удобно ввести **номер периода t = 1, 2, 3, …** — это наш `x`.
- **Тренд** — устойчивое направление. Линейный тренд — та же регрессия `y = a + b·t`, только `x` — время. `b` — средний прирост за период.
- `ПРЕДСКАЗ.ЛИНЕЙН(новый_x; известные_y; известные_x)` — одно значение прогноза (в Excel 2013 и старше — просто `ПРЕДСКАЗ`, в новых версиях она сохранена для совместимости).
- `ТЕНДЕНЦИЯ(известные_y; известные_x; новые_x)` — массив прогнозов сразу для нескольких `новые_x`. Результаты `ПРЕДСКАЗ.ЛИНЕЙН`, `ТЕНДЕНЦИЯ` и `a + b·t` из `ЛИНЕЙН` **совпадают** — это одна и та же модель.
- **Главная опасность — экстраполяция.** Модель описывает данные, а не будущее. На 1–3 периода вперёд — приемлемо, на 36 — гадание: рынок, конкуренты, инфляция, ёмкость. Правило: горизонт прогноза ≲ 10–20 % длины ряда.
- **Сезонность**: если график «зубчатый» (лето/зима, кварталы), прямая проходит «посередине» и не годится. Excel 2016+: `ПРЕДСКАЗ.ETS(целевая_дата; значения; временная_шкала; сезонность)` — экспоненциальное сглаживание, учитывает сезон. Также: Данные → Лист прогноза (строит автоматически с доверительным интервалом).

### Сценарий демонстрации (2 мин)

Лист `2_Временной_ряд`: график с трендом, продлённым на 3 периода. Показать, что C28 (`ПРЕДСКАЗ.ЛИНЕЙН`) = D28 (`ТЕНДЕНЦИЯ`) = `H4 + H3·25`. Затем поменять t на 60 в формуле — получится ≈ 720; спросить, верим ли.

### Ответы к практике 2

**2А** (24 месяца, `y = 294,5 + 7,09·t`, R² = 0,906; средний рост ≈ 7,1 тыс. руб. в месяц):

| Месяц | t | ПРЕДСКАЗ.ЛИНЕЙН / ТЕНДЕНЦИЯ | ПРЕДСКАЗ.ETS (*) |
|---|---|---|---|
| янв 2026 | 25 | **471,6** | 486,4 |
| фев 2026 | 26 | **478,7** | 497,9 |
| мар 2026 | 27 | **485,8** | 509,3 |
| **Итого I кв.** | | **≈ 1 436** тыс. руб. | ≈ 1 494 |
| дек 2026 | 36 | 549,6 | — |

Почему прогноз на t = 60 (≈ 720) ненадёжен: он в 2,5 раза длиннее ряда; предполагает, что ничего не меняется; погрешность растёт с удалением от данных (доверительный интервал расширяется); нет учёта насыщения рынка.

**2Б (*)** (квартальные продажи мороженого): линейный тренд `ТЕНДЕНЦИЯ` даёт ≈ 303, 311, 319, 327 для всех четырёх кварталов 2026 г. — одинаково «серые» значения, R² = **0,095** (тренд объясняет < 10 % разброса). `ПРЕДСКАЗ.ETS(...; 4)` даёт ≈ 218, 317, 432, 240 — воспроизводит сезонную волну (пик в Q3). Вывод: прежде чем прогнозировать, **посмотри на график**.

## 3. Анализ «что если» (57–65 мин)

### Что рассказать

Модель прибыли кафе (лист `3_What-if`):

- Спрос `Q = a − b·P` = 2000 − 8·P (коэффициенты «получены регрессией», как в задании 1Б).
- Выручка `P·Q`, переменные затраты `VC·Q`, постоянные `FC`.
- Прибыль `= (P − VC)·Q − FC`. При P = 150: Q = 800, прибыль **32 000** руб.

Три инструмента — все в **Данные → Анализ «что если»**:

1. **Подбор параметра** (Goal Seek) — обратная задача. Диалог: *Установить в ячейке* (только формула!) → *Значение* (число) → *Изменяя значение ячейки* (только число, не формула!). Excel перебирает значения, пока результат не совпадёт (точность — Файл → Параметры → Формулы → относительная погрешность).
   - Подводные камни: несколько решений (какое найдёт — зависит от начального значения); решения нет (просит прибыль 100 000, а максимум 32 200 — Excel сообщит «решение не найдено»); изменяемая ячейка должна реально влиять на целевую.
2. **Таблица данных** (Data Table) — много прямых задач за раз = **анализ чувствительности**. Правила для таблицы с одной переменной (значения в столбце):
   - значения входа — в столбце (A22:A34), ссылки на результаты (`=B11`, `=B12`, `=B15`) — в строке **над** первым значением и **правее** его (B21:D21); угловая ячейка A21 пуста;
   - выделить весь блок A21:D34 → Таблица данных → «Подставлять значения по **строкам** в» = `$B$4` (значения идут вниз по строкам, поэтому — «по строкам»);
   - Excel заполняет блок формулой массива `{=ТАБЛИЦА(;B4)}` — отдельные ячейки редактировать нельзя, удалять — только целиком.
   - Две переменные: угловая ячейка содержит формулу результата (`=B15`), значения одной переменной — вправо по строке, другой — вниз по столбцу; в диалоге указывают обе ячейки.
   - Таблицы данных могут замедлять книгу; есть режим «Автоматически, кроме таблиц данных» (тогда F9).
3. **Диспетчер сценариев** — именованные наборы значений входных ячеек (Пессимистичный / Базовый / Оптимистичный). Добавить → имя → изменяемые ячейки `B5;B7;B8` → значения. Кнопка **Отчёт → Структура**, ячейка результата `B15` — сводная таблица на новом листе. Удобно для презентации руководству: «в худшем случае 3 тыс., в лучшем 55 тыс.».

### Сценарий демонстрации (3 мин)

1. В решении открыть лист `3_What-if`, поменять цену в B4 на 200 → прибыль 16 000; вернуть 150.
2. Подбор параметра: установить B15 = 20 000, изменяя B4. Получится ≈ 116 (или ≈ 194 — если стартовать с 200). Обсудить: два решения — какое выбрать управленцу? (Обычно более низкая цена — больше клиентов, доля рынка; либо более высокая — меньше нагрузка на бариста. Зависит от цели.)
3. Показать готовую таблицу данных 3.4 и щёлкнуть по любой ячейке — в строке формул `{=ТАБЛИЦА(;B4)}`.

## 4. Типичные ошибки учеников

| Ошибка | Как исправить |
|---|---|
| Перепутан порядок аргументов: `ЛИНЕЙН(x; y)` | Первый аргумент всегда **известные_y** (то, что прогнозируем). |
| Из `ЛИНЕЙН` взяли первое число как `a` | Первое число — наклон `b`, второе — `a`. |
| `#ЗНАЧ!` при `ЛИНЕЙН` в старом Excel | Нужно Ctrl + Shift + Enter или обёртка `ИНДЕКС(…; 1; 1)`. |
| `#ИМЯ?` для `ПРЕДСКАЗ.ЛИНЕЙН` / `ПРЕДСКАЗ.ETS` | Версия Excel ниже 2016 — использовать `ПРЕДСКАЗ`; ETS недоступна. |
| Подбор параметра: «ячейка должна содержать формулу» | Целевая ячейка — формула (B15), изменяемая — число (B4), не наоборот. |
| Подбор параметра меняет число в «зелёной» ячейке модели | Ученик указал изменяемой ячейкой формулу — Excel заменил её числом. Ctrl + Z. |
| Таблица данных вся из одного числа | Выделен неверный диапазон (без строки формул) или входная ячейка указана «по столбцам» вместо «по строкам». |
| В Таблице данных ссылка на результат стоит не там | Для столбца значений: формулы — в строке над первым значением, правее угловой ячейки. |
| Пытаются удалить одну ячейку таблицы данных | «Нельзя изменить часть таблицы данных» — выделить блок целиком. |
| Прогноз на t = 60 называют «точным» | Обсудить горизонт и доверительный интервал. |
| Разделитель аргументов | Русская локализация — `;`, английская — `,`. |
