## Шпаргалка

**Модель** — формулы, связывающие *входы* (параметры) и *выход* (результат). Прямая задача: входы → выход. Обратная: нужный выход → какой вход? Прогноз — вывод модели за пределы имеющихся данных, всегда с погрешностью.

**Линейная регрессия** `y = a + b·x`. `b` — на сколько меняется `y` при росте `x` на 1. `a` — `y` при `x = 0`. **R²** (0…1) — какая доля изменений `y` объяснена моделью.

| Что нужно | Формула (русский Excel) | Английское имя |
|---|---|---|
| Наклон b | `=НАКЛОН(y; x)` | SLOPE |
| Свободный член a | `=ОТРЕЗОК(y; x)` | INTERCEPT |
| R² | `=КВПИРСОН(y; x)` | RSQ |
| b и a одной формулой | `=ЛИНЕЙН(y; x)` → массив `{b; a}` | LINEST |
| Одно число из ЛИНЕЙН | `=ИНДЕКС(ЛИНЕЙН(y; x); 1; 1)` — b, `…; 1; 2)` — a | INDEX |
| Полная статистика (5 строк × 2) | `=ЛИНЕЙН(y; x; ИСТИНА; ИСТИНА)`; R² — в строке 3, столбце 1 | |
| Прогноз в одной точке | `=ПРЕДСКАЗ.ЛИНЕЙН(новый_x; y; x)` | FORECAST.LINEAR |
| Прогноз для диапазона точек | `=ТЕНДЕНЦИЯ(y; x; новые_x)` | TREND |
| Прогноз с сезонностью | `=ПРЕДСКАЗ.ETS(дата; y; даты; длина_сезона)` | FORECAST.ETS |

Первый аргумент — всегда **известные y** (то, что предсказываем). `ЛИНЕЙН` выдаёт сначала **b**, потом **a**. При нескольких `x` коэффициенты идут в **обратном порядке** (последний x — первым), `a` — в конце. В Excel 2016/2019 формулы массива вводятся через **Ctrl + Shift + Enter**.

**Анализ «что если»** — вкладка *Данные → Анализ «что если»*:

- **Подбор параметра** — обратная задача. *Установить в ячейке* — формула результата; *Значение* — нужное число; *Изменяя значение ячейки* — ячейка с числом (входом).
- **Таблица данных** — результат для многих значений входа сразу. Значения входа — столбиком; ссылки на результаты (`=B15`) — в строке над первым значением, правее угловой ячейки; выделить весь блок → «Подставлять значения по строкам в» — ячейка входа.
- **Диспетчер сценариев** — сохранённые наборы входов (пессимистичный/базовый/оптимистичный) и сводный отчёт.
